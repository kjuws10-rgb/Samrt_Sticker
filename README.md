# Smart Sticker

Windows용 캡처·스티커 메모 초안입니다.

## 현재 기능

- 전체 화면 캡처 후 PNG로 보관하고 이미지 미리보기가 포함된 메모 자동 생성
- 여러 메모 창, 텍스트 편집, 색상 변경, 항상 위 고정, 삭제
- 창 위치·크기·내용·첨부 이미지 자동 저장 및 앱 재시작 시 복원

## 실행

```powershell
dotnet run
```

사용자 데이터와 캡처 이미지는 `%LOCALAPPDATA%\SmartSticker`에 저장됩니다.

향후: 영역 지정 캡처, 전역 단축키, 체크리스트/서식, 검색, 알림 기능을 추가할 수 있습니다.
